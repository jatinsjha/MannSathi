# MannSathi logo kit

Open **logo-comparison.png** to see the three designs side by side. Each design folder contains the same set of files.

| Design | Where it works well |
| --- | --- |
| **Daybreak** | A poster or college group announcement. The open book and sunrise carry forward the teal and gold of the existing MannSathi icon. |
| **In Good Company** | A chat-group avatar or community flyer. The two overlapping speech bubbles stay distinct in one color. |
| **Pagefold** | A small app icon, sticker or monochrome stamp. The folded bookmark forms the letter M. |

| File | Use |
| --- | --- |
| `profile.png` | A 1024 × 1024 square profile picture with a solid background. Upload the whole square and center the platform's circular crop. |
| `favicon-32.png` | A 32 × 32 browser or small interface icon. |
| `symbol.svg` and `symbol.png` | A free-standing, full-color symbol on transparency. Use it on white or another pale background. |
| `wordmark-on-light` | The symbol and MannSathi name for light backgrounds. |
| `wordmark-on-dark` | The symbol and MannSathi name for dark backgrounds. |
| `symbol-black` and `wordmark-black` | Solid black artwork with transparent cutouts for single-ink printing. A printer can change all black fills to one spot color. |
| `share-card.png` | A ready-made 1200 × 630 graphic for a group announcement or link preview. Add the launch URL in your post. |

Use PNG for social posts and slide editors. Wordmark PNGs are 1600 pixels wide. Use the matching SVG for signs, large prints and design work. All lettering in the SVGs is outlined. Keep the proportions locked when resizing and leave space around the symbol. For a circular avatar or a favicon, the symbol is easier to read than the full name.
